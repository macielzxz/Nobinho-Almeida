# 💻 Site Nobinho Almeida

Site institucional desenvolvido para apresentar informações sobre Nobinho Almeida, sua trajetória e conteúdos digitais relacionados ao projeto.

O site conta com uma interface moderna, navegação intuitiva e recursos interativos, adaptando-se a diferentes tamanhos de tela.


## ✨ Funcionalidades

- **Página inicial:** apresentação visual e navegação entre as seções.
- **Biografia:** seção dedicada à trajetória e às informações do perfil apresentado.
- **Player de áudio:** reprodução dos jingles diretamente no navegador.
- **Download de músicas:** opção para baixar os arquivos de áudio.
- **Galeria de figurinhas:** exibição de 12 figurinhas disponíveis no site.
- **Download de figurinhas:** opção para baixar o pacote completo em formato ZIP.
- **Menu responsivo:** navegação adaptada para dispositivos móveis.
- **Animações de interface:** elementos que aparecem durante a rolagem da página.
- **Barra de progresso:** indicador visual do avanço da rolagem.
- **Links externos:** acesso ao perfil do Instagram.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, layout responsivo, animações e efeitos visuais.
- **JavaScript** — interatividade, menu mobile, animações durante a rolagem e barra de progresso.
- **Google Fonts** — utilização das fontes Poppins e Inter.

## ▶️ Como executar o projeto

Como o projeto utiliza HTML, CSS e JavaScript puro, não é necessário instalar dependências ou configurar um servidor de aplicação para visualizar a versão local.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar as alterações durante o desenvolvimento.
